\# Cognitive Workspace



Cognitive Workspace is a collaborative workspace designed to help users organize,

manage, and work with information in one place.



\## Purpose



The project aims to provide a centralized workspace where users can manage

their work and information efficiently through a web-based application.



\## Technology Stack



\- Frontend: Next.js

\- Styling: Tailwind CSS

\- Backend: FastAPI

\- Database: Supabase

\- Authentication: Supabase Auth

\- Version Control: Git and GitHub
